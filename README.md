# dotnet-journey

\# C# / .NET Journey



A repository documenting my journey of learning C# and .NET through hands-on projects.



\## Goal



The purpose of this repository is to build practical programming skills by creating progressively more advanced C# applications.



Each project focuses on new language features and programming concepts.



\---



\## Projects



| # | Project | Status | Topics |

|---|---------|--------|--------|

| 001 | Age Calculator | ✅ | Variables, Console I/O, `int.Parse()`, `if/else`, String Interpolation |

| 002 | Car Rental | ✅ | `>=`, `\&\&`, `ToLower()`, String Comparison |

| 003 | BMI Calculator | ⏳ | `double`, `else if` |
