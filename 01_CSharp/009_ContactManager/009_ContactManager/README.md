\# Contact Manager



A C# console application for managing contacts using objects and a dynamic collection.



\## Features



\- Adds new contacts

\- Displays all saved contacts

\- Updates existing contact details

\- Removes selected contacts

\- Validates contact numbers

\- Prevents empty contact details

\- Runs continuously until the user exits



\## Concepts Used



\- Classes and objects

\- Properties

\- Constructors

\- `List<Contact>`

\- CRUD operations

\- Object creation with `new`

\- Accessing and updating object properties

\- Methods with collection parameters

\- `while` and `for` loops

\- `switch` statement

\- `int.TryParse()`

\- `string.IsNullOrWhiteSpace()`

\- List indexing and `RemoveAt()`

\- Early returns



\## How to Run



Open a terminal in the project directory and run:



```console

dotnet run

```
