\# Grade Analyzer



A simple C# console application that analyzes five student scores and displays a summary of the results.



\## Features



\- Accepts five scores from the user

\- Stores the scores in an array

\- Calculates the average score

\- Finds the highest and lowest scores

\- Determines whether the student passed or failed

\- Displays the average with two decimal places



\## Concepts Used



\- Arrays

\- Zero-based indexing

\- `for` loop

\- `foreach` loop

\- Array `Length` property

\- User input with `Console.ReadLine()`

\- Type conversion with `int.Parse()`

\- Type casting from `int` to `double`

\- Conditional statements

\- String interpolation

\- Numeric formatting with `F2`



\## How to Run



Open a terminal in the project directory and run:



```console

dotnet run

```
