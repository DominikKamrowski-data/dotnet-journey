\# Product Inventory



A C# console application for managing products and their stock quantities.



\## Features



\- Adds products with a name, price and initial quantity

\- Displays all products

\- Restocks selected products

\- Sells products while checking stock availability

\- Calculates the total value of each product

\- Calculates the total value of the entire inventory

\- Validates user input



\## Concepts Used



\- Classes and objects

\- Constructors

\- Properties and private setters

\- Encapsulation

\- `List<Product>`

\- Methods with parameters and return values

\- `decimal` and `int` data types

\- `TryParse()`

\- `foreach` and `for` loops

\- Conditional statements

\- Object selection using list indexes

\- Numeric formatting with `F2`
