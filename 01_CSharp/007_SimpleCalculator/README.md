\# Simple Calculator



A C# console calculator that performs multiple arithmetic operations during a single application session.



\## Features



\- Adds, subtracts, multiplies and divides numbers

\- Supports decimal numbers

\- Allows the user to perform multiple calculations

\- Handles invalid operation symbols

\- Prevents division by zero

\- Displays results with two decimal places



\## Concepts Used



\- Methods

\- Method parameters

\- Return values

\- `double` and `double.Parse()`

\- `switch` statement

\- `while` loop

\- Boolean flags

\- Conditional statements

\- String conversion with `ToLower()`

\- String interpolation

\- Numeric formatting with `F2`



\## How to Run



Open a terminal in the project directory and run:



```console

dotnet run

```
