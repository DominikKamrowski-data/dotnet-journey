\# Expense Tracker



A C# console application for recording, displaying and managing personal expenses.



\## Features



\- Adds expenses with a description, amount, category and date

\- Displays all recorded expenses

\- Filters expenses by category

\- Calculates the total value of all expenses

\- Removes selected expenses

\- Validates user input

\- Runs continuously until the user chooses to exit



\## Expense Categories



\- Food

\- Transport

\- Entertainment

\- Bills

\- Other



\## Concepts Used



\- Classes and objects

\- Constructors

\- Properties

\- `List<Expense>`

\- Enumerations with `enum`
