\# Multiplication Table



A simple C# console application that generates a multiplication table for a number selected by the user.



\## Features



\- Accepts a number from the user

\- Generates a multiplication table from 1 to 10

\- Allows the user to generate multiple tables

\- Accepts both uppercase and lowercase answers

\- Displays a message before closing the application



\## Concepts Used



\- `while` loop

\- `for` loop

\- Nested loops

\- User input with `Console.ReadLine()`

\- Type conversion with `int.Parse()`

\- Arithmetic operations

\- Increment operator `++`

\- String interpolation

\- String conversion with `ToLower()`



\## How to Run



Open a terminal in the project directory and run:



```console

dotnet run

```
