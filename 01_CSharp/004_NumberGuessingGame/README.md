# Number Guessing Game



A simple C# console game in which the application generates a random number between 1 and 100 and the player tries to guess it.



## Features



- Generates a random number between 1 and 100

- Accepts multiple guesses from the player

- Indicates whether the guess is too low or too high

- Counts the number of attempts

- Displays a message when the correct number is guessed



## Concepts Used



- Random number generation with `Random`

- `while` loop

- User input with `Console.ReadLine()`

- Type conversion with `int.Parse()`

- Conditional statements: `if` and `else if`

- Increment operator `++`

- String interpolation



## How to Run



Open a terminal in the project directory and run:



```console

dotnet run

```
