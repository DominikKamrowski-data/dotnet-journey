# Bank Account



A C# console application that simulates basic bank account operations using an encapsulated class.



## Features



- Creates an account for a selected owner

- Deposits money

- Withdraws money

- Displays account information

- Prevents deposits and withdrawals with invalid amounts

- Prevents withdrawing more than the current balance

- Runs continuously until the user exits



## Concepts Used



- Classes and objects

- Constructors

- Encapsulation

- Get-only properties

- Properties with private setters

- Class methods

- Methods returning `bool`

- The `decimal` data type

- Input validation with `decimal.TryParse()`

- Passing objects to methods

- `while` loop

- `switch` statement

- Numeric formatting

- Boundary-case testing



## How to Run



Open a terminal in the project directory and run:



```console

dotnet run

```
